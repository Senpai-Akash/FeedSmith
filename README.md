# FeedSmith

> Craft the feed you actually want.

FeedSmith is a project that helps users shape their social media recommendations around the content they actually care about.

Instead of spending days training a new social media account through random likes, follows, and searches, FeedSmith aims to create a personalized strategy based on the user's interests.

## 🎯 Goal

Help users build a more relevant and personalized social media feed in less time.
